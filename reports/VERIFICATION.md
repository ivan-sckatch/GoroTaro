# Проверка ГороТаро

> Исторический отчёт версии 0.1.0. Результаты и ограничения ниже относятся к 2 октября 2026 года. Актуальный статус 0.5.0, включая ручные проверки, подтверждённые пользователем 3 ноября, — в [отчёте реализации](REDESIGN-IMPLEMENTATION-2026-11-02.md). Прежнее требование EXACT для release снято: 0.5.0 использует встроенный COMPOSED. Старые измерения и APK не описывают текущую поставку.

Дата: 2 октября 2026 года. Проверена техническая поставка 0.1.0; публичный выпуск не выполнялся.

## Результат

Debug APK собирается, устанавливается и запускается на Android 15. Release APK также собирается; для локального измерения отдельная QA-копия подписана тестовым ключом. Пользовательская поставка — `dist/GoroTaro-debug.apk`. Сборка не требует Android Studio; инструкции находятся в README.

| Проверка | Фактический результат |
|---|---|
| JVM-тесты domain | 10 успешно, без пропусков |
| Android-тесты Room и UI | 15 успешно |
| Python-тесты контентного инструмента | 4 успешно |
| Три UI-сценария, 320 dp, шрифт 200%, тёмная тема | 3 успешно |
| Android Lint debug | 0 ошибок, 13 предупреждений |
| Проверка 22 оригиналов по SHA-256 и размерам | 22 успешно |
| EXACT-черновики дня | 22/22 ключей, 44 варианта, 0 утверждённых ключей |

12 предупреждений Lint связаны с более новыми версиями зависимостей; версии текущей поставки закреплены и проверены сборкой. Ещё одно предупреждение — рекомендация применить KTX вместо конструктора ColorDrawable. Ошибки и предупреждения о резервном копировании устранены.

## Что проверяют тесты

Domain: выбор без повторов для 1/3/7 карт; стабильный порядок; ключи перестановок; невозможные конфигурации; переход дня, понедельника, года и зон; переходы летнего времени; циклы вариантов длиной 2 и 3; проверка полноты EXACT, статусов, дублей и неизвестных карт; однопроходная безопасная подстановка опций; ограничения длины вопроса и вариантов.

Диагностика распределения: фиксированный seed 20261002, 110 000 выборов по одной карте, χ²=17,3152 при заранее заданном пороге 60. Это проверка реализации, а не доказательство криптографической случайности. Production использует SecureRandom без тестового seed.

Android: 20 одновременных запросов недели дают одну запись и один шаг мешка; повтор requestId возвращает тот же снимок; следующий осознанный запрос получает другой вариант; отсутствие EXACT не сохраняет результат; исключение до commit откатывает запись и мешок; удаление истории сохраняет период; полный сброс разрешает новый результат; закрытие и открытие базы с диска сохраняет карты, текст, заметку и раскрытие; новая версия контента не меняет старый период; переход через полночь и перевод часов назад возвращают правильные снимки; данные решения не попадают в периодические расклады.

Импорт проверен на полном тестовом пакете дня из 22 ключей: успешная активация, отклонение повреждённого файла, сохранение прежней activeVersion и запрет повторной перезаписи версии. Тестовые строки находятся только в androidTest и не входят в поставляемый контент.

UI: день открывается одним действием; Activity recreation сохраняет результат; семантика закрытой карты не раскрывает название; «Открыть все» даёт общий смысл; пустой вопрос блокирует решение; вопрос и обе опции сохраняются и показаны в результате. Ввод в тестах выполняется через семантические действия полей. Визуально просмотрены скриншоты обычного и увеличенного шрифта; исправлены контраст системных панелей и переносы нижней навигации.

## Измерения

Среда: Pixel 2 AVD, Android 15/API 35, x86_64, 2 048 МиБ RAM, WHPX, SwiftShader. Это эмулятор на компьютере, а не референсный телефон с 4 ГБ RAM.

| Показатель | Результат и метод |
|---|---|
| Запуск release | 656, 853, 966, 838, 994 мс; медиана 853 мс. `am start -W TotalTime`, перед каждым запуском force-stop; файловые кэши остаются прогретыми |
| История 10 000 записей | Вставка 2 051 мс, получение и декодирование первых 50 записей 18 мс; debug/in-memory Room на эмуляторе |
| Debug APK | 14 175 806 байт |
| Release APK unsigned | 10 220 890 байт |
| 22 оригинальные карты | 29 788 957 байт |
| WebP карт 600 px | 1 773 198 байт |
| Миниатюры 160 px | 247 040 байт |
| Кэш декодированных изображений | Ограничен 16 МиБ |

Размеры и запуск записаны в `performance.json` и `release-startup.json`. Основные пары цветов текста дают контраст от 5,74:1 до 16,18:1; проверка находится в `contrast.json`. Цвет gold применяется только для декора.

Измерение запуска — TTID, не время завершения всех фоновых операций. Целевые бюджеты из задания для конкретного реального устройства, нового расклада ≤200 мс и чтения сохранённого расклада ≤100 мс остаются неподтверждёнными отдельными измерениями. Значение страницы истории нельзя выдавать за эти метрики.

## Границы приёмки

Технический прототип готов для установки и проверки. Полная публичная приёмка ещё не завершена:

- Нужна человеческая редактура 44 черновиков дня. Неделя и решение не имеют полного EXACT-корпуса: по 9 240 ключей и 2–3 утверждённых варианта для каждого.
- Импорт проверен на ключах дня; измерение большого репрезентативного корпуса ещё не выполнено. Текущий импорт ограничен стартовой major22 и размером 64 МБ ZIP/128 МБ после распаковки.
- Нужна проверка на реальных устройствах, включая TalkBack, клавиатуру, масштаб 150%, планшет и минимальную Android 8.0. Автотест семантики не заменяет ручную проверку экранного диктора.
- Восстановление проверено через Activity recreation и повторное открытие Room с диска. Отдельный сценарий убийства процесса во время анимации ещё требует ручной проверки.
- Требуются ключ release-подписи владельца, окончательные материалы и подтверждение прав на публичное распространение иллюстраций. SDK и требования магазина нужно перепроверить перед публикацией.

Аккаунты, сеть, реклама, покупки и напоминания не добавлены в первую техническую поставку. Неполный корпус не скрывается: COMPOSED есть только в debug и явно подписан, а release требует утверждённый EXACT. Черновики автоматически не становятся approved.
