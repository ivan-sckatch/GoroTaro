# Реализация переделки ГороТаро 0.5.0

Рабочая версия Android / RuStore: `C:\Users\user\Documents\ChatGPT\GoroTaro`. Проект Яндекс Игр не изменялся. Основание — `RUSTORE-REDESIGN-PLAN.md`, разрешение пользователя «реализуй».

## Изменения

1. На главной два основных сценария: разбор ситуации и сравнение вариантов. День и неделя доступны в сворачиваемой «Моей практике». Можно вернуться к последней записи или продолжить последнюю ситуацию.
2. `situation3` — отдельный тип с позициями «Что происходит / Что осложняет / На что опереться». Тема и вопрос необязательны. Темы общей ситуации, общения и работы меняют ракурс составного текста. Вопрос сохраняется как контекст, без семантического анализа. Новая ситуация создаётся явной кнопкой, без общей 14-дневной паузы; повторный запрос с тем же идентификатором возвращает один снимок.
3. Составной движок 5 (`composed-local-5`): один синтез, одна связь первой и третьей карт, отдельное действие ресурса с ограничением препятствия, отдельный вопрос карты по желанию. Удалены дополнительные пересказы целей и повтор общей рекомендации в действии. Детали позиций используют банк формулировок и остаются свёрнутыми. Последовательное раскрытие не сопровождается автоматическим толкованием под картами.
4. Одна личная заметка видна сразу; поля «Что произошло?» и «Что оказалось полезным?» открываются через «Вернуться и дополнить». Автосохранение после 600 мс паузы, перед штатной навигацией, при уходе Activity в фон. Черновик также хранится в SavedStateHandle. Есть статус и повторная ручная попытка при ошибке. Мгновенное принудительное убийство процесса до записи в БД не считается гарантированно защищённым; этот случай требует испытания на устройстве.
5. Поиск включает тему ситуации. При обновлении поисковый индекс перестраивается в транзакции. Избранное, поиск по вопросу и трём заметкам, экспорт и восстановление сохранены.
6. В release новые расклады используют встроенный составной режим без внешнего EXACT-пакета. Меню отладки, ручной предпросмотр, выбор режима и импорт ZIP доступны через debug. Демонстрационный EXACT остаётся в debug-assets. Контент сохраняет статус draft; редактура автоматически не подтверждается.

## Совместимость

- Старый `general3` остаётся с прежними названиями позиций и 14-дневной паузой. Записи доступны из истории; новых снимков этот экран не переименовывает.
- Старые тексты и версии сохраняются. Новые поля JSON имеют значения по умолчанию. Схема Room остаётся v2; миграция 1 → 2 сохранена.
- Новые резервные копии имеют формат 2, включают ситуации и темы. Формат 1 читается. Более новые версии отклоняются с сообщением о неподдерживаемом формате; восстановление проверяет весь файл до транзакции. Коллизии не затирают локальные снимки и заметки.
- Варианты и случайность карт не меняются ради сокрытия повторов. Добавлен `situation3` в редакторский Python-инструмент.
- Исходники и схемы до изменений: `baseline-2026-11-02/sources-before-redesign.zip`. В архиве сохранены относительные пути модулей. Существующие изменения Git не удалялись, коммит не создавался.
