# Обновление 0.4.0 — 7 октября 2026

Все шесть улучшений внесены в исходники: последовательное раскрытие; более связные итоги и действия; заметки о последующих событиях; поиск и избранное; понятные названия; резервная копия с восстановлением. По последующему уточнению пользователя пояснения убраны из-под карт: после всех карт показываются общий итог и полезный шаг, а пояснения позиций ниже свёрнуты по умолчанию.

- Проверка SQLite `tools/test_history_migration.py` прошла: фактический SQL миграции сохраняет старый JSON и скрытие, соответствует экспортированной схеме 2 и сохраняет ограничение уникальности периода.
- Kotlin debug и release, генерируемый Room Java и Android-тесты компилируются.
- Android Lint debug: 0 ошибок, 2 рекомендации KTX.

## Новые проверки

JVM: полный цикл резервной копии с заметками, избранным, скрытием и состояниями вариантов; совместимость старых снимков; отказ при неверной версии, дубликатах, неверных позициях, индексах раскрытия и состояниях вариантов; размер файла; порядок раскрытия; простой текстовый экспорт; зависимость практического шага от каждой карты и положения.

Android-тесты, добавлены и скомпилированы: восстановление без дублей и перезаписи локальных заметок; сохранение скрытого закрепления и паузы; отказ до записи повреждённого файла; поиск по русскому тексту до ограничения страницы и фильтр избранного; миграция Room из реальной схемы 1 с восстановлением поисковых полей; отсутствие пояснений при раскрытии и их открытие по нажатию после общего итога; сохранение новых заметок и избранного после пересоздания Activity.

## Сохранность и ограничения

Room 1 → 2 добавляет `searchText` и `favorite` без удаления таблиц. Существующие снимки и толкования не пересчитываются. Поисковые поля заполняются порциями по 250 записей. Новые JSON-поля `happened`, `useful`, `favorite` имеют совместимые значения по умолчанию.

Копия истории содержит полный текст и иллюстрационные метаданные сохранённых карт, все заметки, избранное, раскрытие, скрытые снимки и состояния вариантов. Настройки и импортированные наборы контента не входят. JSON не зашифрован; об этом написано перед экспортом. Ограничения: 32 МБ, 10 000 снимков, 30 000 состояний вариантов. Размер сохранённых данных проверяется до их полной загрузки, затем проверяется размер готового файла.

Весь файл проверяется перед восстановлением. Вставка атомарна; совпадения идентификатора, запроса и периода пропускаются. Локальные заметки, скрытие и существующие состояния вариантов не перезаписываются. При конфликте двух разных результатов одного периода остаётся локальный результат. Скрытые снимки включены, чтобы не терять закрепления и 14-дневную паузу. Полный сброс очищает новые заметки, избранное и запрос поиска вместе с остальными личными данными.

Новые составные тексты используют `composed-demo-4`, движок — `4`. Для недели, решения и общего расклада есть разные связи позиций; также учитывается связь первой и третьей карт. Примеры для редакторского просмотра обновлены в `reports/NARRATIVE-EXAMPLES.md`. Формальные тесты не заменяют содержательную редактуру всех комбинаций.

Проверки выполнены офлайн с локальной JDK 17. Песочница Windows блокировала закрытие JAR в `ZipFileSystemProvider`; компиляция Java и Lint завершены при разрешённом локальном запуске вне песочницы. Служебный Kotlin daemon отключён через `-Pkotlin.compiler.execution.strategy=in-process`.
